## Lab Activities

**Lab 1 — Map the Instagram Customer Journey and Account Readiness** · Connect the business objective, audience evidence, customer journey, tool permissions, account readiness, risks, and human approval gates.

**Lab 2 — Write and Test the Instagram Agent Prompt Contract** · Create a reusable G-C-A-T-E contract with evidence boundaries, tool permissions, output checks, escalation rules, and failure behaviour.

**Lab 3 — Create the Instagram Content and Creative Kit** · Develop seven connected content briefs with reviewed captions, hashtag rationales, image or storyboard directions, brand checks, and rights records.

**Lab 4 — Build the Content Calendar Agent and Publishing Workflow** · Turn the content kit into a seven-day calendar and a draft-first workflow that stops before any live publishing action.

**Lab 5 — Build the Comment and Direct-Message Response Router** · Route synthetic Instagram messages by intent and risk while protecting personal data and escalating sensitive cases.

**Lab 6 — Create the UGC, Review, Privacy and Escalation Runbook** · Review synthetic user-generated content for permission, privacy, copyright, truth, retention, and incident handling.

**Lab 7 — Build the Instagram Insights Dashboard and Evidence-Linked Report** · Validate a synthetic performance export, calculate defined metrics, diagnose the funnel, and recommend one bounded learning action.

**Lab 8 — Design and Simulate the Instagram Ads, Retargeting and Optimisation Loop** · Build a recommendation-only campaign policy with guardrails, approval, cooldown, rollback, and a traceable decision log.

## About

This repository contains the complete courseware and connected lab materials for **Agentic AI for Instagram Marketing** (**C695**) by Tertiary Courses / Tertiary Infotech. The learning journey progresses from agent foundations and content planning to community care, measurement, advertising, and controlled optimisation.

All eight labs use the synthetic **Harbour & Hearth** bakery scenario. Learners build one `C695-campaign-pack` across the course, so each output becomes an input to the next activity. Public posting, customer-data processing, targeting changes, and advertising spend remain behind explicit human approval gates.

### What you'll learn

| # | Activity | Concepts |
|---|----------|----------|
| **1** | **Journey and Readiness Map** | Business objective, audience evidence, customer journey, account readiness, tool roles, risk tiers |
| **2** | **Agent Prompt Contract** | G-C-A-T-E instructions, grounded inputs, permissions, schemas, tests, stop conditions |
| **3** | **Content and Creative Kit** | Message hierarchy, content pillars, captions, hashtags, creative briefs, brand and rights checks |
| **4** | **Calendar and Publishing Workflow** | Calendar logic, validation, approval evidence, duplicate prevention, failure handling |

| **7** | **Insights Dashboard and Report** | Data validation, metric definitions, funnel diagnosis, source-linked findings, bounded action |

## Getting Started

### Prerequisites

- An organisation-approved generative AI assistant
- A text or Markdown editor
- A spreadsheet application for CSV and dashboard work
- Access to the files in this repository
- Optional view-only access to an Instagram Professional account, Meta Business Suite, or an n8n practice workspace

No live posting, messaging, audience changes, or advertising spend is required.

### 1. Clone the repository

```bash
git clone https://github.com/tertiarycourses/C695-Agentic-AI-for-Instagram-Marketing.git
cd C695-Agentic-AI-for-Instagram-Marketing
```

### 2. Start with the Learner Guide

Open **[LG-Agentic AI for Instagram Marketing (C695).md](LG-Agentic%20AI%20for%20Instagram%20Marketing%20%28C695%29.md)** for the course concepts, preparation guidance, and complete lab instructions.

### 3. Complete the connected labs in order

1. Read [`labs/README.md`](labs/README.md).
2. Create a working folder named `C695-campaign-pack`.
3. Complete Labs 1 to 8 in sequence because each lab reuses reviewed outputs from earlier labs.
4. Use only the supplied synthetic resources unless your trainer explicitly approves another safe dataset.
5. Keep every approval, exception, test, and decision record in the campaign pack.
